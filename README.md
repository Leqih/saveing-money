# 省钱小局

一个把记账做成卡牌游戏的 demo：每周抽规则卡，每天记账时马上知道有没有打破规则，帮你对花出去的钱更有感觉。

## 怎么打开

直接用浏览器打开 `index.html` 就能玩，不需要安装任何东西。所有数据只存在当前页面里，刷新就会从头开始。

## 怎么玩

- **每周一，抽 5 留 3**：留下的 3 张规则卡这周同时生效，比如"今天不点外卖""晚上 10 点后一分不花"。每张牌写着守住能加多少倍率。
- **每记一笔，马上知道**：记之前就能看到会不会碎牌、倍率怎么变。碎了的牌当天不算倍率，第二天零点恢复；按周算的牌碎到周日。
- **碎了也别破罐破摔**：按天算的牌碎了以后，当天不再花额度外的钱，晚上拿回一半倍率（止损）；按周算的牌碎了以后，每再超一次，当天倍率 −1。
- **重叠的牌不能一起留**：零元日（+4）已经包含了外卖克星、步行者、存钱罐、冷静期，这几张不能和它同时留。
- **今天的分 = 今天剩下的钱 × 倍率**：倍率从 1 开始，每张守住的牌加上去。晚上"出牌，结束今天"时会播一段计分。
- **一周攒够目标分就过关**：拿星星，没过不扣钱。周日晚上看周结算，周一早上逛商店、抽新牌。

## 主要功能

- 首次使用：设预算、选弱点（会估算你的第一周）、周中加入按短周算
- 首页：三张牌和倍率、今日还能花、本周分数、常用一键记账（按住直接记下）
- 记一笔：常用、备注、自定义类别、改和删、待买清单（等满 24 小时再决定）
- 通知铃铛：规则提醒、晚上提醒、待买清单回访、止损提示，不占首页的位置
- 账单：今天的流水、月历、本月花在哪、月度回顾（习惯有没有变）
- 牌库：8 张规则卡、解锁、毕业（连续 2 周守住 6/7 天，底倍率永久 +1，周目标分 +25%；对账员不会毕业）
- 每周的延续：续留一张牌、难度注（白注 → 黑注）、商店（星星当货币，卖解锁、指定发牌、第 4 个牌槽、胶水）
- 规则细节：没记账的一天先按 0 分，第二天确认真的没花就补底分（只算底倍率，牌不加倍率）；当天花超的钱从明天的额度里扣，周日花超的从下周一扣；记吃饭时可以标"外卖送的"，按外卖算
- 演示用：点左上角的日期可以切换时间，或直接跳到周日晚上
