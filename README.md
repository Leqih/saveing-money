# Penny Round（省钱小局）

一个把记账做成卡牌游戏的 demo：每周抽规则卡，每天记账时马上知道有没有打破规则，帮你对花出去的钱更有感觉。界面是英文、美元的美国版。

## 怎么打开

直接用浏览器打开 `index.html` 就能玩，不需要安装任何东西。抽完第一周的牌后，进度会存在这个浏览器里，刷新或关掉再开都会接着玩；想从头来，去设置里点 Start over。

在 Claude 桌面 App 的预览面板里看时，要通过本地服务器打开（配置在 `.claude/launch.json`，名字是 `penny-round`），因为面板直接预览文件时不会加载旁边的 CSS 和 JS 文件。也可以自己运行 `python -m http.server 8765`，再打开 http://localhost:8765。

## 代码结构

没有构建步骤，全是普通的 `<script>`（不是 ES 模块，这样双击文件也能打开）。这些脚本共用一个全局作用域，按下面的顺序加载：

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面骨架：手机外框、状态栏 |
| `styles.css` | 全部样式 |
| `js/cards.js` | 卡牌插画和卡面渲染 |
| `js/rules.js` | 26 张规则卡、类别、计分 `scoreDay`、透支 `carryDebt`、周目标 `targetFor`、星星 `starsFrom`。都是纯函数，不读全局状态 |
| `js/state.js` | 全局状态 `S`、预算；`dayContext` 把 `S` 转成计分用的参数，`evaluate` 是给页面用的计分入口 |
| `js/views.js` | 弹层基础、主页、账单、牌库 |
| `js/draw.js` | 每周抽牌：撕卡包、滑动选牌、侧键快捷跳转 |
| `js/log.js` | 记一笔、收据、当晚计分、规则卡详情 |
| `js/setup.js` | 首次设置、设置页、导入银行流水、个人页 |
| `js/sheets.js` | 银行对账、月度回顾、早报和通知、周结算、商店 |
| `js/flow.js` | 结束一天、开始新一周、输入框的处理 |
| `js/actions.js` | 每个按钮做什么：`data-act` 查 `ACTIONS` 表，其余按数据属性查 `BY_DATA` 表，按功能分组 |
| `js/save.js` | 存档到浏览器、刷新后恢复、启动 |

## 怎么玩

- **每周一，抽 8 留 3**：留下的 3 张规则卡这周同时生效，比如 "No takeout today"、"Nothing spent after 10 pm"。每张牌写着守住能加多少倍率（+1 到 +5）。
- **每记一笔，马上知道**：记之前就能看到会不会碎牌、倍率怎么变。碎了的牌当天不算倍率，第二天零点恢复；按周算的牌碎到周日。
- **碎了也别破罐破摔**：按天算的牌碎了以后，当天不再花额度外的钱，晚上拿回一半倍率（止损）；按周算的牌碎了以后再超支，当天还会继续扣倍率。
- **重叠的牌不能一起留**：比如 Zero Day（+4）已经包含了 Takeout Nemesis、Walker、Piggy Bank 等，这几张不能和它同时留。
- **今天的分 = 今天剩下的钱 × 倍率**：倍率从 1 开始，每张守住的牌加上去。晚上 "Play cards, end today" 时会播一段计分。
- **一周攒够目标分就过关**：拿星星，没过不扣钱。周日晚上看周结算，然后选下周的难度、续留一张牌，再抽新牌。
- **领星星前对一下账**：填这周银行卡或 Venmo 里实际花了多少，比记下的多出两成以上（且超过 $30）这周星星就不算；不对账星星减半。

## 主要功能

- 首次使用：先用三页讲清楚这是什么、每天和每周怎么玩（设置里的 How to play 也是这三页），再设预算（每周额度 =（月收入 − 固定支出 − 存款）÷ 4.3 − 每天必需消费额度 × 7）、选弱点（可以导入银行流水自动找）、选频率（会估算你的第一周）、周中加入按短周算
- 首页：复古 CRT 屏显示今天还能花多少，旋钮可以切到今日得分和守住几张牌；本周规则卡、今日流水、"End today"
- 改以前的账：账单里以前的每一笔都能点开改金额、类别、备注或删掉，只改账不改分，那天的收据会注明改过；周日对账按改后的数字算
- 记一笔：常用项（Save favorite 存下的会出现在记账页顶部）、备注、自定义类别、改和删、愿望清单（等满 24 小时再决定）
- 个人页：徽章、星星、诚实连胜、通知、银行、设置
- 银行当裁判：连上银行后照样自己记账，晚上计分前对一遍，漏记的要补；连续 7 晚没漏记送一瓶胶水，14 晚再送一颗星
- 账单：流水、月历、花在哪、月度回顾（习惯有没有变）
- 牌库：26 张规则卡、按累计星星解锁、毕业（连续 2 周守住 6/7 天，底倍率永久 +1，周目标分 +25%；Bookkeeper 和 Full Ledger 不会毕业）
- 每周的延续：续留一张牌、难度（White → Black Stake，越难过关星星倍数越高）、商店（星星当货币，卖提前解锁、指定发牌、第 4 个牌槽（目标分 +25%）、胶水）
- 规则细节：没记账的一天先按 0 分，确认真的没花就补底分（只算底倍率，牌不加倍率；周日在周结算前问）；当天花超的钱从明天的额度里扣（最多扣半天，多的每 $1 让本周目标分 +3），周日花超的从下周一扣；记吃饭时可以标 "Delivered"，按外卖算
- 跟着真实日期走：隔了几天再打开，会先把这几天结束掉。离开那天记过的照常结算，之后的几天算没记账，早上一起问一次「是不是真的没花」；跨过周日就先做周结算，下一周从今天是星期几开始（短周），整周没玩的直接跳过
- 周五及以后才加入（或者隔了几周回来时已是周五之后），剩下不到 4 天就算热身：照常计分，但不发星星、不能调难度，第一个完整的周从下周一开始
- 在设置里改每周额度，从下周一开始生效，这周的额度和目标分不变
- 演示用：点左上角的日期可以切换时间，或直接跳到周日晚上；用鼠标时，手机屏幕里的光标会变成模拟手指的灰色圆点
- 看界面用：点手机侧边的实体键（左边三个或右边电源键），第一次会跳过引导直接进主页（用默认预算、留下推荐的 3 张牌），之后每按一次在主页、账单、牌库之间切换
